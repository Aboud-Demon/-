# دعوة زفاف اسماعيل ورحمة

دعوة زفاف تفاعلية مبنية باستخدام React وVite، بتصميم عربي متجاوب وحركات سينمائية وموسيقى اختيارية تبدأ عند فتح الدعوة.

## التشغيل محليًا

يتطلب Node.js 24.x وnpm.

```bash
npm ci
npm run dev
```

لإنشاء نسخة الإنتاج ومعاينتها:

```bash
npm run build
npm run preview
```

## النشر على GitHub وVercel

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات هذا المشروع إلى المستودع، مع تضمين `package-lock.json` وملفات `public/`.
3. في Vercel اختر **Add New → Project** ثم استورد مستودع GitHub.
4. استخدم إعدادات البناء المحددة في `vercel.json`: أمر البناء `npm run build` ومجلد الإخراج `dist`.
5. انشر المشروع. سيُنشئ Vercel معاينة للتغييرات اللاحقة، وينشر الفرع الإنتاجي عند تحديثه.

يوجد سير عمل GitHub Actions في `.github/workflows/build.yml` للتحقق من تثبيت الحزم وبناء المشروع عند كل تحديث أو طلب دمج.

## الملفات المهمة

- `src/` — مكونات الدعوة والأنماط والبيانات.
- `public/audio/wedding-music.mp3` — الموسيقى المستخدمة في الدعوة.
- `public/icons/` و`public/manifest.webmanifest` — أيقونة وبيانات تطبيق الويب.
